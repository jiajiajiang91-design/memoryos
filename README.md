# ◇ MemoryOS

> 整合多个 AI 的记忆，无痛切换。
>
> *让每一次对话与思考，都成为可延续的资产。*

[English](./README.en.md) · [下载安装包](../../releases) · [Issues](../../issues)

MemoryOS 是一个桌面应用，把你和 ChatGPT / Claude / Gemini / Cursor 等多个 AI 的工作记忆整理成**每个项目一页的「记忆卡片」**。开新对话时把这一页交给任何 AI，它能在 30 秒内接上进度。所有内容都是你电脑上的普通 Markdown 文件，不需要注册，不上传任何数据。

![MemoryOS 首页](./docs/screenshots/v0.3.0/01_welcome.png)

---

## 它解决什么问题

在多个 AI 之间切换工作时，每开一个新对话都要重新介绍自己是谁、项目做到哪了。ChatGPT 的记忆只在 ChatGPT 里生效，Claude 的项目功能只在 Claude 里生效，互相带不走。

MemoryOS 不替代任何 AI 工具。它在这些工具之间做一层共用的工作记忆：记忆只整理一份，每个 AI 都能读。

---

## 记忆卡片：每个项目一页

每个项目的记忆浓缩成一页卡片，分五个部分：**项目卡**（这是什么、给谁用）、**当前状态**（做到哪了、卡在哪）、**约束与决策**（定过什么规矩，每条带日期和出处）、**上次对话总结**（上次停在哪）、**历史档案**（过时内容的去处）。另有一张全局的**关于我**，记你的身份和协作偏好。

![项目主页 — 记忆卡片完整可见](./docs/screenshots/v0.3.0/02_dashboard_cards.png)

卡片有三条规矩：

1. **一页以内** — 全文控制在 1200 字内。注入太长，AI 反而会忽略中间的内容。
2. **来源分明** — 你拍板的决定和 AI 的建议分开标记，AI 的想法不会被写成你的决定。
3. **过时即归档** — 被替代的旧决策移入历史档案，退出第一页，但永远不删除，随时可查。

页面上显示的内容，就是 AI 开场读到的内容，没有暗处。

## 两种用法

### 复制粘贴（任何 AI 都可以）

四步完成一轮：开场把「开始对话指令」粘贴给 AI，它读取记忆卡片接上进度；正常工作；结束时把「结束对话指令」粘贴给它，它整理出本次总结和卡片的新版本；回到 MemoryOS 导入并确认。

![产品内置的复制粘贴教程 — 四步](./docs/screenshots/v0.3.0/03_copy_paste_tutorial.png)

### 与 Claude 直连（免复制粘贴）

在 Claude Desktop 的 设置 → Extensions 里装上 `memoryos.mcpb`，填入工作区路径。之后开场说一句「读取我的项目记忆」，结束说一句「把总结存回去」，整轮就完成了。产品内有逐步教程。

![产品内置的 Claude 连接教程](./docs/screenshots/v0.3.0/06_connect_claude.png)

> 网页版 ChatGPT / Gemini 暂时连不上本地程序（浏览器限制），这些 AI 继续用复制粘贴，结果汇入同一个收件箱。

## AI 说的不算，你确认了才算

AI 写回的更新先进入**收件箱**，主页会出现待审提醒。打开确认页，新旧内容以划线对比呈现：删掉的划线，新增的高亮。AI 自己的建议单独列出，可以采纳也可以驳回，驳回之后不会再出现。

![确认页 — 划线对比新旧内容，AI 建议单独列出](./docs/screenshots/v0.3.0/04_review.png)

![主页的待审提醒](./docs/screenshots/v0.3.0/05_inbox_pending.png)

信得过之后，可以给单个项目打开**信任模式**：直连写回的常规更新自动保存，省去每次确认；内容对不上号时（比如新版基于过时的卡片），仍会停下来请你过目。AI 的建议在任何模式下都需要你亲自采纳。

## 设计原则

1. **AI 整理，你确认** — 所有写入都经过你的勾选；直连写回也先进收件箱
2. **记忆保持现时** — 同一主题只留最新版，过时内容归档而非删除
3. **来源可查** — 每条决策带日期和原话出处，建议和决定从源头分开
4. **不读取你的对话** — 总结由 AI 在对话里生成、由你交回，软件从不抓取聊天记录
5. **删除可逆** — 删项目走系统回收站，5 秒内可撤销

## 主要功能

- **记忆卡片** — 每个项目一页，五个部分，所见即 AI 所得
- **完整中英双语** — 一键切换，界面和指令模板都跟着语言走
- **8 个预置 AI + 自定义** — ChatGPT / Claude / Gemini / Grok / Cursor / Codex / DeepSeek / Kimi
- **与 Claude 直连** — 装一个扩展，读取记忆、存回总结都不用复制粘贴
- **收件箱与确认页** — 划线对比新旧，AI 建议可采纳可驳回，驳回不再出现
- **信任模式** — 按项目开关，常规更新自动保存，存疑内容仍请你过目
- **旧项目一键升级** — 没有记忆卡片的旧项目，一条指令让 AI 整理出第一版卡片
- **纯 Markdown** — 用 Obsidian / VS Code / 记事本都能打开，拷贝文件夹就是完整备份
- **App 内编辑** — 卡片和核心资料可以直接在弹窗里改
- **一键反馈** — 写完一键复制并打开 GitHub Issues

## 安装

### 直接用安装包（推荐 · Windows）

下载 [Releases](../../releases) 里的 `.exe`（一键安装）或 `.msi`（受管安装）。

Windows 会弹「未知发行者」警告（暂未做代码签名），点「更多信息 → 仍要运行」即可。软件不联网，也不读取你指定文件夹以外的文件。

### 从源码构建

需要：Node 18+ / Rust 1.70+ / Windows 上需要 VS Build Tools（C++ Desktop）

```bash
git clone https://github.com/jiajiajiang91-design/memoryos.git
cd memoryos
npm install
npm run tauri dev      # 开发模式
npm run tauri build    # 打包安装包
```

## 数据存在哪

默认 `~/Documents/MemoryOS/`，结构：

```
MemoryOS/
├── about_me.md                          ← 关于我（全局）
└── projects/
    └── <项目名>/
        ├── project.json                  ← 元数据
        ├── cards.md                      ← 记忆卡片（AI 开场读的就是它）
        ├── decisions.md                  ← 决策档案（过时条目的去处）
        ├── 00_context.md                 ← 旧版项目说明（升级后冻结为档案）
        └── sessions/                     ← 历史对话总结
            └── session_2026-06-10_2130.md
```

任意编辑器都能打开，整个文件夹拷贝就是完整备份。

> 文件名保留英文，方便 AI 识别和外部工具兼容；界面上显示中文友好名。

- **Tauri 1.5** — Rust 内核的桌面框架，Windows 安装包约 1.8 MB
- **React 18 + TypeScript** — 界面层
- **Tailwind CSS** — 样式，重点色是克莱因蓝 #002FA7
- **`trash` crate** — Rust 端实现回收站删除与还原
- **Vite** — 构建
